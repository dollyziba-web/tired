# Prospira Digital Agency

Exact recreation and mirror of the official **PROSPIRA** digital agency website: [https://prospira-agency-iuzt.vercel.app/](https://prospira-agency-iuzt.vercel.app/).

## Overview

Prospira builds elite digital products that grow businesses. Custom Web, Mobile, SaaS, and AI solutions.

This repository contains the exact production website:
- **Homepage** (`index.html`): Hero with 3D product mockup showcase, animated statistics counter, infinite client logo marquee (`GOOGLE`, `META`, `VERCEL`, `STRIPE`, `LINEAR`, `AWS`, `MICROSOFT`, `ADOBE`), 6 service disciplines, call-to-action, and 4-column footer.
- **Services** (`services.html` & `services/index.html`): Digital Solutions Built for Scale + Interactive Project Cost Estimator.
- **Portfolio / Work** (`portfolio.html` & `portfolio/index.html`): Selected Works with category filtering (`All`, `Web`, `Game Dev`, `SaaS`, `Systems`).
- **Process** (`process.html` & `process/index.html`): The Prospira Way execution roadmap.
- **About** (`about.html` & `about/index.html`): Company philosophy (*More Than Migration, Evolution*), values, and team overview.
- **Contact** (`contact.html` & `contact/index.html`): Project inquiry form and AI Project Advisor.

## Running Locally

Run the included local server:
```bash
node server.cjs
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.
