# Prospira Digital Agency

High-performance digital agency web application recreated from [https://prospira-agency-iuzt.vercel.app/](https://prospira-agency-iuzt.vercel.app/).

## Overview

Prospira builds elite digital products that grow businesses. Custom Web, Mobile, SaaS, and AI solutions.

### Features
- **Hero Showcase**: 3D perspective mockup, custom typography, dual call-to-actions.
- **Statistics Counter**: Animated metric cards (*300+ Projects, 10+ Years, 20+ Technologies, 100% Client Focused*).
- **Client Logo Strip**: Infinite marquee featuring leading industry brands.
- **Core Disciplines / Services Grid**: 6 interactive service cards with hover glow and tags.
- **Interactive Scope & Cost Estimator** (`/services`).
- **Selected Works & Portfolio Filter** (`/portfolio`).
- **The Prospira Way Roadmap** (`/process`).
- **Company Philosophy & Guiding Principles** (`/about`).
- **Direct Project Inquiry & AI Project Advisor** (`/contact`).

## Quick Start

### 1. Run Exact Mirror Server
```bash
node server.cjs
```
Visit [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001).

### 2. React + Vite Development
```bash
npm install
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run preview
```
